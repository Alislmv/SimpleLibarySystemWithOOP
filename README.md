## Library Management System

About the Project
This is a simple Library Management System created with Python and Object-Oriented Programming (OOP).

The program allows users to manage books and students in a library.

## Features
- Show all books
- Show all students
- Borrow a book
- Return a book
- Search for a book by ID
- Check book availability
- Exit the program

## Classes

### 1. Book
Stores book information:
- Book ID
- Title
- Author
- Page count
- Availability status

### 2. Student
Stores student information:
- Student ID
- Name
- Borrowed books

Students can borrow and return books.

### 3. Libary
Manages the library:
- Add books
- Add students
- Show books
- Show students
- Search for books and students
- Borrow and return books

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- Lists
- Classes and Objects
- Loops
- Conditional Statements

## How to Run

1. Make sure Python is installed.
2. Open the project folder.
3. Run the main.py file.
4. Choose an option from the menu.
